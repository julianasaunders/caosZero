# CaosZero 2.0

Bem-vindo à wiki do **CaosZero 2.0**, um automatizador de tarefas com arquivos
desenvolvido para o projeto integrador de **Sistemas Operacionais** (tema 4.5).

## O que é

Uma CLI em Python que:

- organiza arquivos por categoria;
- renomeia em massa;
- arquiva arquivos antigos;
- gera relatórios em Markdown, CSV e JSON;
- registra cada execução em um journal;
- desfaz a última execução;
- diagnostica recursos do sistema operacional.

> Por padrão, nada é alterado. A execução real exige `--apply`.
