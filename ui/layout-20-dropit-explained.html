Associações (regra → ação)

Regra: Nome *.jpg, *.png
Filtra por extensão de imagem
→ Mover para Imagens/
prioridade: alta · status: ativa
Regra: Nome *.pdf, *.docx
Filtra por extensão de documento
→ Mover para Documentos/
prioridade: alta · status: ativa
Regra: Tamanho > 100 MB
Arquivos grandes
→ Mover para Compactados/
prioridade: média · status: ativa
Regra: Data > 180 dias
Arquivos antigos
→ Arquivar em Arquivo/AAAA/
prioridade: baixa · status: ativa
Associações são aplicadas por prioridade. Se nenhum casar, o arquivo vai para "Outros".
