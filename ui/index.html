Como testar: abra cada arquivo HTML no navegador (duplo clique) ou use o botão "Abrir". A simulação é local (JavaScript), sem backend. Para conectar de verdade ao CaosZero, basta substituir a função de simulação por chamadas à CLI ou a um pequeno servidor Python (FastAPI/Flask) que invoque caoszero.py.

Escolha um layout (ou peça ajustes) — eu então adapto o escolhido para a aplicação real (integração com o backend, persistência de configuração e empacotamento).
